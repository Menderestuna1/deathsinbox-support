# Death's Inbox Support

GitHub Pages için hazır resmi destek ve gizlilik sitesi.

## Yayınlama
1. Bu klasördeki `index.html`, `privacy.html` ve `style.css` dosyalarını repository kök dizinine yükleyin.
2. GitHub → Settings → Pages.
3. Source: Deploy from a branch.
4. Branch: `main`, Folder: `/ (root)`.
5. Save.
